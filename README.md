# Nyri

Оболочка для [niri](https://github.com/YaLTeR/niri) на [Quickshell](https://quickshell.org)
в стиле Material 3 Expressive. Цвета берутся из обоев через matugen и расходятся
по niri, GTK, Qt и терминалу.

## Что есть

- **Панель.** Собирается из значков: перетаскиваешь их по уменьшенной панели в
  настройках. Островки, полоса или чипы, сверху или снизу, может прятаться.
- **Живой остров** у часов: запись экрана, трансляция, микрофон и камера, таймеры,
  секундомер, загрузки, копирование файлов, обновление системы, VPN, наушники,
  телефон, музыка. Эти же процессы видны на экране блокировки.
- **Плеер** вырастает из острова: обложка, перемешивание и повтор, громкость
  плеера, выбор между плеерами, синхронный текст песни из lrclib.
- **Шторка (Mod+N).** Плитки раскрываются в свои страницы: Wi-Fi с подробностями,
  Bluetooth, звук, приватность, телефон. Внизу карусель: плеер, телефон, таймер
  и секундомер, листается свайпом и колесом.
- **Звук.** Выход для каждого приложения, 10-полосный эквалайзер с пресетами,
  у наушников заряд, режим «музыка / звонки» и выбор кодека.
- **Телефон** через KDE Connect: заряд и сеть, найти, отправить файл или буфер,
  открыть память телефона.
- **Док.** Закреплённые и запущенные приложения, увеличение под курсором,
  список окон при наведении, счётчик непрочитанных уведомлений.
- **Рабочий стол.** Десяток виджетов в нескольких видах. Режим правки: каталог
  с превью, перетаскивание, размер, сетка, на всех столах или только на одном.
- **Обои.** Генератор на 20 стилей и 33 палитры, у каждой есть светлая и тёмная
  версия. Обои могут быть живыми: каждый стиль двигается по-своему, на столе и
  под экраном блокировки. Тёмная тема и обои меняются вместе, по расписанию или руками.
- **Поиск (Mod+Space).** Приложения, окна, файлы, настройки, калькулятор и
  конвертер, `таймер 5м`, `> команда`.
- **Снимки и запись (Print).** Выделить область или кликнуть для всего экрана;
  при записи отдельно включаются звук системы и микрофон.
- **Ещё:** экран блокировки, окно polkit, буфер обмена, экранное время,
  переключатель окон.

Всё приходит событиями, поллинга нет. В простое шелл берёт около 0,15 % одного ядра.

## Установка

Проверено на Arch с niri 26.04 и Quickshell 0.3.1.

```bash
sudo pacman -S niri quickshell matugen jq fuzzel cliphist wl-clipboard grim slurp \
    wf-recorder hyprpicker brightnessctl wireplumber playerctl tesseract tesseract-data-rus \
    curl libnotify glib2 kconfig plasma-workspace wlsunset libqalculate resvg swappy \
    python-gobject kitty plocate kdeconnect
```

Шрифты: Rubik, Material Symbols Rounded, JetBrainsMono Nerd Font.

```bash
git clone https://github.com/yzewe/Nyri ~/nyri
~/nyri/bin/nyri-install
```

Репозиторий должен лежать в `~/nyri`. Установщик ставит ссылки в `~/.config`,
а то, что заменил, складывает в `~/.config-nyri-backup/`. Потом перезайди в сессию.
Откатиться можно командой `~/nyri/bin/nyri-install --undo`.

## Клавиши

`Mod` — Super.

| Клавиши | Что делают |
|---|---|
| Mod+Space | Поиск |
| Mod+N | Шторка |
| Mod+I | Настройки |
| Mod+Y | Студия обоев |
| Mod+V | Буфер обмена |
| Mod+X | Питание и выход |
| Mod+Alt+L | Заблокировать |
| Alt+Tab | Переключатель окон |
| Print, Mod+Shift+S | Снимок или запись; при записи — стоп |
| Mod+Shift+X / A | Текст с экрана / Google Lens |
| Mod+Shift+C | Пипетка |
| Mod+Shift+W | Прятать панель |
| Mod+F / Mod+Ctrl+F / Mod+Shift+F | Развернуть / до краёв / на весь экран |
| Mod+/ | Все клавиши |

С мышью:

| Клавиши | Что делают |
|---|---|
| Mod + нажатие колеса | Обзор |
| Mod + боковые кнопки | Соседняя колонка; с Shift — перенести колонку |
| Mod+Shift + колесо | Листать колонки вбок |
| Mod+Alt + колесо | Громкость |
| Mod+Alt + нажатие колеса / боковые | Пауза / следующий и предыдущий трек |

## Обои из терминала

```bash
bin/nyri-wall styles
bin/nyri-wall apply rings Океан 12
bin/nyri-wall apply bauhaus Терракота/dark 7 --scale 0.7
bin/nyri-wall variant dark        # текущие обои на ночь
```

## Попробовать в окне

```bash
bin/nyri-nested --own-bus
```

Запускает niri с Nyri в окне. У окна свои настройки, буфер и шина D-Bus.
Сон и выключение там не работают, пароль не проверяется.
